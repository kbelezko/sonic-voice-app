# Check Strands Documentation

- Before answering Strands Agents SDK questions or planning Strands-related changes, activate the installed `strands` power and verify that its official documentation tools are accessible.
- Search the current official Strands documentation at `strandsagents.com` for the relevant API or pattern instead of relying only on memory.
- Fetch the relevant documentation page when search snippets are insufficient to verify the details.
- If documentation access fails, clearly tell the user what could not be verified before proceeding.
- This rule does not authorize code changes; only create or modify code when the user explicitly requests it.
